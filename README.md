# Отправки

Внутренний сервис учёта поставок товаров на фулфилмент и возвратов.
Каждая отправка сразу дублируется отдельным листом в Google Таблицу «Отправки»
в привычном бухгалтерском формате: бренд → дата → модель → сетка «Размер × Цвет» → «Общ:» → «Общ.кол-во».

## Возможности

- Список отправок по месяцам, сводка (отгружено / возвраты / бренды), поиск по бренду, ИП и модели, фильтры по ФФ и статусу.
- Просмотр отправки: таблицы по каждой модели с итогами по цветам, размерам, бренду; печать.
- Редактор:
  - сетка количеств «размер × цвет» с живыми итогами и навигацией стрелками/Enter;
  - вставка блока чисел из Excel или Google Таблиц (Ctrl+V в ячейку);
  - «= всем»: одно число во все размеры цвета;
  - размеры у модели свои (XS–L по умолчанию, можно добавить XL, 42, 44…);
  - тип модели: **Отгрузка** или **Возврат**;
  - автоподсказки ФФ, брендов, ИП, моделей и цветов из прошлых отправок; артикул подставляется сам, если цвет этой модели у бренда уже был;
  - копирование отправки как шаблона, дублирование модели, Ctrl+S для сохранения.
- Статусы: Черновик → Отправлено → Принято ФФ.
- **С телефона** редактор перестраивается под палец:
  - вместо широкой таблицы — карточка на каждый цвет с крупными полями по размерам и цифровой клавиатурой;
  - Enter переходит к следующему размеру, после последнего — к следующему цвету;
  - «= всем размерам» открывает шторку с быстрыми числами (10, 15, 20, 25…);
  - «Уже отправляли: + Вилка однотон» — модель бренда добавляется целиком со всеми цветами, артикулами и размерами, остаётся вписать количество;
  - «Быстро добавить цвет: + Белый» — цвета, которые уже были у этой модели;
  - готовые модели сворачиваются в строку, чтобы длинная отправка помещалась на экране;
  - кнопка «Сохранить» и итоги всегда внизу экрана.
- Google Sheets: одна отправка — один лист (новые листы появляются первыми). При сохранении лист перезаписывается,
  при удалении отправки он удаляется. Если синхронизация не удалась, данные всё равно сохраняются,
  а на карточке появляется красная точка и кнопка «Синхронизировать».

## Запуск

Нужен Node.js 22.5+ (используется встроенный `node:sqlite`, внешняя БД не нужна).

```bash
npm install
cp .env.example .env   # заполнить
node --env-file=.env --no-warnings server/index.js
```

Откроется на http://localhost:3000. Через Docker:

```bash
docker build -t otpravki .
docker run -d -p 3000:3000 -v otpravki-data:/data --env-file .env otpravki
```

## Подключение Google Таблицы

1. https://console.cloud.google.com → создать проект (или взять существующий).
2. **APIs & Services → Library** → включить **Google Sheets API**.
3. **IAM & Admin → Service Accounts** → *Create service account* → после создания **Keys → Add key → JSON**. Скачается файл ключа.
4. Открыть таблицу «Отправки» → **Настройки доступа** → добавить e-mail сервисного аккаунта
   (`…@….iam.gserviceaccount.com`) с правами **Редактор**.
5. В `.env` указать `SPREADSHEET_ID` и путь к ключу (`GOOGLE_APPLICATION_CREDENTIALS`) или его содержимое (`GOOGLE_SERVICE_ACCOUNT_JSON`).
6. Перезапустить сервис: в логе будет `Google Sheets: включено`, а в шапке у ссылки на таблицу появится зелёная точка.

Существующие листы, сделанные вручную, сервис не трогает: он пишет и удаляет только свои листы.

## Структура

```
server/
  index.js    — HTTP API + раздача фронтенда, вход по паролю
  db.js       — SQLite (таблица shipments, содержимое хранится как JSON)
  model.js    — валидация отправки, итоги, форматы дат
  layout.js   — раскладка отправки в строки листа (формат бухгалтерии)
  sheets.js   — запись листа в Google Sheets API
public/       — интерфейс (без сборки: HTML + CSS + JS)
test/         — тесты (npm test)
```
